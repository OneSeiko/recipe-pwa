# 📖 Книга рецептов — Recipe PWA

Электронная книга рецептов с облачной синхронизацией, фотографиями и офлайн-режимом.

## Возможности

- ☁️ синхронизация рецептов, категорий, фотографий и избранного через Firebase;
- 🔐 отдельная защищённая книга для каждого аккаунта;
- 📱 доступ с телефона, планшета и компьютера после входа под одним email;
- 📴 офлайн-работа: изменения отправляются в облако после восстановления сети;
- 💾 автоматический перенос ранее сохранённых локальных рецептов при первом входе;
- 🖼️ сжатие загружаемых фотографий для экономии места;
- 🔍 поиск, фильтры, категории и избранное;
- 📲 установка как PWA.

## Как пользоваться облаком

1. Откройте сайт: https://onekanmi-spec.github.io/recipe-pwa/.
2. В блоке «Облачная книга» нажмите «Войти и включить облако».
3. На первом устройстве создайте аккаунт. Существующие локальные рецепты автоматически загрузятся в облако.
4. На остальных устройствах войдите с тем же email и паролем.

Каждый вошедший пользователь имеет доступ только к собственной книге. Firebase Authentication определяет пользователя, а правила Firestore не позволяют обращаться к данным другого аккаунта.

## Локальная разработка

    corepack enable
    pnpm install
    cp .env.example .env.local
    pnpm dev

В файле .env.local укажите конфигурацию веб-приложения Firebase.

## Сборка

    pnpm build

Сайт автоматически развёртывается на GitHub Pages после push в main.

## Структура облачных данных

    users/{uid}/recipes/{recipeId}
    users/{uid}/settings/book

Правила доступа находятся в firestore.rules.
